# Cadence Desk

Shows the focus session you started in Cadence on your phone and runs desk breaks while it lasts: a 20-20-20 eye
break every 20 minutes and a stand-up prompt every 50. When VS Code isn't open you're away from the screen, so
nothing prompts anywhere. Your answers and active minutes go back to the app.

Set `cadence.server` in settings, then run **Cadence: Set server token**.
